# PDI - Plano de Desenvolvimento Individual

Sistema de Facilitação e Diagnóstico Organizacional para autoavaliação profunda e reflexiva.

## Funcionalidades

- **Autoavaliação Completa**: Rotina, ambiente, relacionamentos, aprendizado e aspirações
- **Diagnóstico 360°**: Análise de tempo, demandas, liderança e cultura organizacional
- **Relatórios Consolidados**: Para administração com dados de todos os colaboradores
- **Painel Administrativo**: Visualização de PDIs concluídos e busca por departamento

## Fases do PDI

1. **FASE 0**: Verificação de Acesso (Painel Administrativo)
2. **FASE 1**: Coleta de Dados e Boas-Vindas
3. **FASE 2**: Avaliação de Tempo e Demandas
4. **FASE 3**: Ambiente, Relações e Liderança
5. **FASE 4**: Aprendizado, Didática e Desenvolvimento
6. **FASE 5**: Visão de Futuro
7. **FASE 6**: Encerramento e Síntese do PDI

## Estrutura do Projeto

```
PDI_/
├── app.py              # Aplicação principal
├── requirements.txt    # Dependências Python
├── static/            # Arquivos estáticos (CSS, JS)
├── templates/         # Templates HTML
└── data/             # Armazenamento de dados dos PDIs
```

## Tecnologias

- Python/Flask
- HTML/CSS/JavaScript
- Armazenamento local (JSON/SQLite)

## Como Executar

```bash
pip install -r requirements.txt
python app.py
```
